# aroma-pacifico-design-system

Design system of the three Aroma Pacífico applications: coffee grower, transporter and sack lookup

Part of the Aroma Pacífico pilot, the 2026 update of the coffee traceability pilot for Cauca, Huila and Tolima. Work is tracked in [aroma-pacifico-roadmap](https://github.com/aroma-pacifico/aroma-pacifico-roadmap) and on the [Aroma Pacífico Pilot board](https://github.com/orgs/aroma-pacifico/projects/1).

## What lives here

This repository holds the design system, color palette, typography, components, and UX specifications for the three Aroma Pacífico pilot applications: Coffee Grower (offline-first PWA), Transporter (mobile lookup), and Sack Traceability Portal. Distributed AI agent rules and standards are synchronized here from the canonical `aroma-pacifico-ai-agents` repository.
